# Dedup Backup

Dedup Backup es una herramienta para automatizar respaldos mediante deduplicación basada en contenido. Utiliza el algoritmo **BLAKE3** para identificar archivos de forma única y almacena la información en una base de datos **PostgreSQL**, evitando copiar archivos cuyo contenido ya existe.

El proyecto está diseñado para trabajar con grandes volúmenes de datos distribuidos en múltiples discos, priorizando el rendimiento mediante procesamiento paralelo y una arquitectura desacoplada entre exploración, hashing, consulta a la base de datos y copiado.

## Características

* Deduplicación basada en el hash **BLAKE3**.
* Base de datos **PostgreSQL** para el registro de hashes y metadatos.
* Copia únicamente de archivos cuyo contenido no existe previamente.
* Procesamiento paralelo para aprovechar procesadores multinúcleo.
* Ejecución simultánea de múltiples lectores, uno por cada disco o fuente de datos.
* Número configurable de *workers* para el cálculo de hashes.
* Procesamiento por lotes (*batches*) para reducir el número de consultas a la base de datos y mejorar el rendimiento.
* Sistema de perfiles para diferentes configuraciones de respaldo.
* Registro de eventos mediante archivos de log.
* Sistema de colas para desacoplar las distintas etapas del procesamiento.

## Arquitectura

El sistema está compuesto por un proceso principal y uno o varios de procesamiento, permitiendo automatizar completamente la ingesta y deduplicación de dispositivos de almacenamiento.

### 1. Proceso principal

El proceso principal permanece en ejecución esperando nuevas fuentes de datos. Estas pueden provenir de dos formas:

* Conexión automática de un dispositivo de almacenamiento, como memorias USB, discos duros externos, SSD externos o tarjetas SD.
* Ejecución manual desde el menú, seleccionando una carpeta o un disco específico.

Cuando se detecta un nuevo dispositivo, el proceso espera a que el sistema operativo complete su montaje. Una vez que el volumen está disponible y es accesible, inicia automáticamente el procesamiento correspondiente utilizando el perfil configurado, donde el perfil es una base de datos y un path donde se almacenarán los resultados.

### 2. Exploración del sistema de archivos

El proceso de exploración recorre recursivamente todos los directorios de la fuente de datos.

Para evitar trabajo innecesario, únicamente procesa archivos cuyas extensiones pertenecen a un conjunto inmutable (*frozen set*) de extensiones permitidas. Este mecanismo permite realizar búsquedas muy rápidas y filtrar inmediatamente archivos que no forman parte del respaldo.

Cada archivo válido es enviado al proceso de hashing.

### 3. Hashing paralelo

El cálculo de hashes se realiza utilizando un conjunto configurable de *workers*.

Cada *worker* procesa archivos de forma independiente calculando su hash mediante el algoritmo **BLAKE3**, aprovechando múltiples núcleos del procesador para maximizar el rendimiento.

El número de *workers* puede configurarse para cada lector según el hardware disponible.

### 4. Procesamiento por lotes

Los hashes calculados no se consultan individualmente.

Se agrupan en lotes (*batches*) de tamaño configurable y posteriormente se realizan consultas masivas sobre PostgreSQL para determinar cuáles archivos ya existen dentro de la base de datos.

Este enfoque reduce considerablemente el número de consultas y mejora el rendimiento cuando se procesan cientos de miles o millones de archivos.

### 5. Copiado y registro

Para cada lote procesado:

* Los archivos cuyo hash ya existe en PostgreSQL son descartados.
* Los archivos nuevos son asignados como pendientes durante el copiado al directorio definido por el perfil activo.
* Una vez copiados correctamente, se registran como finalizados en PostgreSQL junto con su hash BLAKE3 y sus metadatos.

De esta forma se garantiza que un mismo contenido nunca sea almacenado dos veces, independientemente de su nombre o ubicación original.

## Paralelismo

La arquitectura permite ejecutar múltiples lectores de manera simultánea.

Cada lector puede trabajar sobre una fuente distinta (por ejemplo, un disco externo diferente) y configurarse de manera independiente con:

* Número de *workers* para el cálculo de hashes.
* Tamaño de los lotes (*batch size*).
* Directorio de destino.
* Perfil de respaldo.
* Base de datos PostgreSQL.

Esto permite aprovechar varios dispositivos de almacenamiento al mismo tiempo, distribuyendo la carga entre CPU, memoria y discos para maximizar el rendimiento del proceso de deduplicación.

## Paralelismo

El programa fue diseñado para escalar con el hardware disponible.

Es posible ejecutar múltiples instancias del lector, asignando una a cada disco físico. Cada instancia puede configurarse de manera independiente con:

* Número de *workers* dedicados al cálculo de hashes.
* Tamaño de los lotes (*batch size*).
* Base de datos de destino.
* Directorio de respaldo.

De esta forma es posible aprovechar mejor el ancho de banda de múltiples discos, distribuir la carga entre diferentes dispositivos de almacenamiento y ajustar el consumo de CPU según el equipo.

## Funcionamiento

Para cada archivo:

1. Se localiza el archivo durante la exploración.
2. Se calcula su hash BLAKE3.
3. El hash se agrupa junto con otros en un lote.
4. PostgreSQL determina qué hashes ya existen.
5. Solo los archivos nuevos se copian al destino.
6. Finalmente se registran el hash, la ruta y los metadatos correspondientes.

Este enfoque evita realizar consultas individuales por archivo y reduce significativamente el tiempo total de procesamiento cuando se manejan cientos de miles o millones de archivos.

import traceback

import psycopg2

try:
    from blake3 import blake3
except ModuleNotFoundError:
    blake3 = None

from explorer_hasher import (
    DEFAULT_QUEUE_DIR,
    build_queue_path,
    count_files,
    iter_hashed_files,
    load_hash_queue,

DEFAULT_DB_DSN = os.environ.get("CONSULTER_DB_DSN", "")
DEFAULT_DESTINATION_ROOT = Path(os.environ.get("CONSULTER_COPY_ROOT", "/home/uzr/data_full"))
COPY_CHUNK_SIZE = int(os.environ.get("CONSULTER_COPY_CHUNK_MB", "64")) * 1024 * 1024
DB_RETRIES = int(os.environ.get("CONSULTER_DB_RETRIES", "6"))
DB_RETRY_SLEEP = float(os.environ.get("CONSULTER_DB_RETRY_SLEEP", "0.75"))
FILENAME_MODES = {"hash", "first_name"}

SCHEMA_SQL = """
CREATE TABLE IF NOT EXISTS backup_disks (
    id BIGSERIAL PRIMARY KEY,
    label TEXT,
    mount_path TEXT UNIQUE NOT NULL,
    total_bytes BIGINT,
    free_bytes BIGINT,
    status TEXT,
    created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS disks (
    id BIGSERIAL PRIMARY KEY,
    serial TEXT UNIQUE,
    model TEXT,
    label TEXT,
    filesystem TEXT,
    mount_path TEXT,
    size_bytes BIGINT,
    status TEXT,
    created_at TIMESTAMP DEFAULT NOW(),
    last_seen TIMESTAMP DEFAULT NOW()
);

CREATE TABLE IF NOT EXISTS sessions (
    id BIGSERIAL PRIMARY KEY,
    disk_id BIGINT REFERENCES disks(id),
    status TEXT,
    started_at TIMESTAMP DEFAULT NOW(),
    finished_at TIMESTAMP,
    last_copied_hash TEXT,
    last_copied_path TEXT
);

CREATE TABLE IF NOT EXISTS files (
    id BIGSERIAL PRIMARY KEY,
    hash TEXT UNIQUE NOT NULL,
    size_bytes BIGINT,
    status TEXT,
    name TEXT,
    extension TEXT,
    created_at TIMESTAMP DEFAULT NOW()
);

ALTER TABLE files ADD COLUMN IF NOT EXISTS name TEXT;
ALTER TABLE files ADD COLUMN IF NOT EXISTS extension TEXT;

CREATE TABLE IF NOT EXISTS stored_files (
    id BIGSERIAL PRIMARY KEY,
    file_id BIGINT REFERENCES files(id),
    backup_disk_id BIGINT REFERENCES backup_disks(id),
    relative_path TEXT NOT NULL,
    verified BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP DEFAULT NOW(),
    CONSTRAINT unique_backup_disk_path UNIQUE (backup_disk_id, relative_path)

CREATE INDEX IF NOT EXISTS idx_files_hash ON files(hash);
CREATE INDEX IF NOT EXISTS idx_files_status ON files(status);
CREATE INDEX IF NOT EXISTS idx_sessions_status ON sessions(status);
CREATE INDEX IF NOT EXISTS idx_disks_status ON disks(status);
CREATE INDEX IF NOT EXISTS idx_backup_disks_status ON backup_disks(status);
CREATE INDEX IF NOT EXISTS idx_stored_files_disk_file ON stored_files(backup_disk_id, file_id);
"""

RETRYABLE_DB_ERRORS = (
    psycopg2.errors.DeadlockDetected,
    psycopg2.errors.SerializationFailure,
    psycopg2.errors.LockNotAvailable,
)


def connect_db(dsn: str):
    if not dsn:
        raise ValueError(
            "Debe definir la conexión PostgreSQL. Use CONSULTER_DB_DSN o el argumento --db-dsn."
        )
    return psycopg2.connect(dsn)


def ensure_schema(conn):
    with conn.cursor() as cur:
        cur.execute(SCHEMA_SQL)
    conn.commit()


def run_db(conn, action: str, callback):
    for attempt in range(1, DB_RETRIES + 1):
        try:
            result = callback()
            if not conn.autocommit:
                conn.commit()
            return result
        except RETRYABLE_DB_ERRORS as exc:
            try:
                conn.rollback()
            except Exception:
                pass
            if attempt >= DB_RETRIES:
                raise
            print(
                f"Reintentando DB {action} ({attempt}/{DB_RETRIES}) por bloqueo: {exc}",
                file=sys.stderr,
                flush=True,
            )
            time.sleep(DB_RETRY_SLEEP * attempt)


def get_or_create_backup_disk(conn, mount_path, label=None, total_bytes=None, free_bytes=None, status="online"):
    def query():
        with conn.cursor() as cur:
            cur.execute(
                "INSERT INTO backup_disks (mount_path, label, total_bytes, free_bytes, status) "
                "VALUES (%s, %s, %s, %s, %s) "
                "ON CONFLICT (mount_path) DO UPDATE SET "
                "label = COALESCE(EXCLUDED.label, backup_disks.label), "
                "total_bytes = COALESCE(EXCLUDED.total_bytes, backup_disks.total_bytes), "
                "free_bytes = COALESCE(EXCLUDED.free_bytes, backup_disks.free_bytes), "
                "status = EXCLUDED.status "
                "RETURNING id",
                (mount_path, label, total_bytes, free_bytes, status),
            )
            return cur.fetchone()[0]

    return run_db(conn, "backup_disks upsert", query)


def get_file_row(conn, hash_value):
    def query():
        with conn.cursor() as cur:
            cur.execute("SELECT id, status FROM files WHERE hash = %s", (hash_value,))
            return cur.fetchone()

    return run_db(conn, "files select", query)


def insert_reserved_file(conn, hash_value, file_meta):
    def query():
        with conn.cursor() as cur:
            cur.execute(
                "INSERT INTO files (hash, size_bytes, status, name, extension) "
                "VALUES (%s, %s, %s, %s, %s) "
                "ON CONFLICT (hash) DO NOTHING RETURNING id",
                (
                    hash_value,
                    file_meta.get("size_bytes"),
                    "reserved",
                    file_meta.get("name"),
                    file_meta.get("extension"),
                ),
            )
            row = cur.fetchone()
            return row[0] if row else None

    return run_db(conn, "files insert", query)


def mark_file_reserved(conn, file_id, file_meta):
    def query():
        with conn.cursor() as cur:
            cur.execute(
                "UPDATE files SET "
                "status = %s, "
                "size_bytes = COALESCE(files.size_bytes, %s), "
                "name = COALESCE(files.name, %s), "
                "extension = COALESCE(files.extension, %s) "
                "WHERE id = %s",
                (
                    "reserved",
                    file_meta.get("size_bytes"),
                    file_meta.get("name"),
                    file_meta.get("extension"),
                    file_id,
                ),
            )

    run_db(conn, "files reserve", query)


def reserve_hash(conn, hash_value, file_meta):
    row = get_file_row(conn, hash_value)
    if row:
        file_id, status = row
        if status == "copied":
            return file_id, "copied", False
        mark_file_reserved(conn, file_id, file_meta)
        return file_id, "reserved", False

    file_id = insert_reserved_file(conn, hash_value, file_meta)
    if file_id:
        return file_id, "reserved", True

    row = get_file_row(conn, hash_value)
    if not row:
        raise RuntimeError(f"No se pudo reservar hash {hash_value}")

    file_id, status = row
    if status == "copied":
        return file_id, "copied", False
    mark_file_reserved(conn, file_id, file_meta)
    return file_id, "reserved", False


def update_file_status(conn, file_id, status):
    def query():
        with conn.cursor() as cur:
            cur.execute("UPDATE files SET status = %s WHERE id = %s", (status, file_id))

    run_db(conn, f"files status {status}", query)


def ensure_stored_file(conn, file_id, backup_disk_id, relative_path):
    def query():
        with conn.cursor() as cur:
            cur.execute(
                "INSERT INTO stored_files (file_id, backup_disk_id, relative_path) "
                "VALUES (%s, %s, %s) "
                "ON CONFLICT (backup_disk_id, relative_path) DO UPDATE SET "
                "file_id = EXCLUDED.file_id, verified = FALSE",
                (file_id, backup_disk_id, relative_path),
            )

    run_db(conn, "stored_files upsert", query)


def sanitize_filename(name: str, fallback: str) -> str:
    cleaned = re.sub(r"[\\/:*?\"<>|\x00-\x1f]+", "_", name.strip())
    cleaned = re.sub(r"\s+", " ", cleaned).strip(" .")
    return cleaned or fallback


def destination_for(destination_root: Path, digest: str, file_meta: dict, filename_mode: str = "hash") -> tuple[Path, bool]:
    """Determina la ruta de destino y retorna (path, was_renamed)"""
    extension = (file_meta.get("extension") or "").lower()
    extension_dir = extension.lstrip(".") or "no_ext"
    was_renamed = False

    if filename_mode == "first_name":
        safe_name = sanitize_filename(file_meta.get("name") or digest, digest)
        name_path = Path(safe_name)
        if extension and not name_path.suffix:
            safe_name = f"{safe_name}{extension}"
            name_path = Path(safe_name)
        content_dest = destination_root / extension_dir / safe_name
        
        # Si existe un archivo con el mismo nombre, usar sufijo file(n)
        if content_dest.exists():
            suffix = name_path.suffix or extension
            stem = name_path.stem or digest
            counter = 1
            while True:
                new_name = f"{stem}_file({counter}){suffix}"
                content_dest = destination_root / extension_dir / new_name
                if not content_dest.exists():
                    was_renamed = True
                    break
                counter += 1
                if counter > 10000:  # Evitar bucle infinito
                    raise RuntimeError(f"No se puede crear nombre unico para {stem}")
        
        return content_dest, was_renamed

    content_dest = destination_root / extension_dir / digest
    if extension:
        content_dest = content_dest.with_suffix(extension)
    return content_dest, was_renamed


def copy_file(source_path: str, destination_path: Path):
    destination_path.parent.mkdir(parents=True, exist_ok=True)
    tmp_path = destination_path.with_name(f".{destination_path.name}.{os.getpid()}.part")
    try:
        with open(source_path, "rb") as source, tmp_path.open("wb") as destination:
            shutil.copyfileobj(source, destination, length=COPY_CHUNK_SIZE)
        shutil.copystat(source_path, tmp_path)
        os.replace(tmp_path, destination_path)
    finally:
        try:
            tmp_path.unlink(missing_ok=True)
        except OSError:
            pass


def verify_file_hash(file_path: Path, expected_hash: str) -> bool:
    """Verifica que el hash BLAKE3 del archivo coincida con el esperado."""
    if blake3 is None:
        print(f"Advertencia: blake3 no disponible, omitiendo verificacion para {file_path}", file=sys.stderr, flush=True)
        return True
    
    try:
        hasher = blake3()
        with open(file_path, "rb") as f:
            while True:
                chunk = f.read(COPY_CHUNK_SIZE)
                if not chunk:
                    break
                hasher.update(chunk)
        computed_hash = hasher.hexdigest()
        return computed_hash == expected_hash
    except Exception as exc:
        print(f"Error verificando hash de {file_path}: {exc}", file=sys.stderr, flush=True)
        return False


def print_progress(disk_id: str, current: int, total: int):
    print(f"PROGRESS:{disk_id}:{current}:{total}", flush=True)


def count_queue_records(queue_path: str | Path) -> int:
    try:
        with Path(queue_path).open("r", encoding="utf-8") as queue_file:
            return sum(1 for line in queue_file if line.strip())
    except FileNotFoundError:
        return 0


def copy_one_file(
    conn,
    digest: str,
    file_meta: dict,
    backup_disk_id: int,
    destination_root: Path,
    summary: dict,
    filename_mode: str,
):
    summary["scanned"] += 1
    relative_path = file_meta.get("relative_path") or file_meta.get("name") or file_meta.get("path")
    file_id, status, created = reserve_hash(conn, digest, file_meta)

    if status == "copied":
        summary["already_registered"] += 1
        ensure_stored_file(conn, file_id, backup_disk_id, relative_path)
        return

    if created:
        summary["reserved"] += 1
    else:
        summary["retried"] += 1

    content_dest, was_renamed = destination_for(destination_root, digest, file_meta, filename_mode)
    try:
        expected_size = file_meta.get("size_bytes")
        if content_dest.exists() and (expected_size is None or content_dest.stat().st_size == expected_size):
            update_file_status(conn, file_id, "copied")
            ensure_stored_file(conn, file_id, backup_disk_id, relative_path)
            summary["copied_and_verified"] += 1
            return

        copy_file(file_meta["path"], content_dest)
        
        # Verificar integridad del archivo copiado
        if verify_file_hash(content_dest, digest):
            update_file_status(conn, file_id, "copied")
            ensure_stored_file(conn, file_id, backup_disk_id, relative_path)
            summary["copied_and_verified"] += 1
            if was_renamed:
                summary["renamed"] += 1
            print(f"Copiado y verificado {file_meta['path']} -> {content_dest}", flush=True)
        else:
            update_file_status(conn, file_id, "failed")
            ensure_stored_file(conn, file_id, backup_disk_id, relative_path)
            summary["failed"] += 1
            print(f"Error de integridad: hash no coincide para {content_dest}", file=sys.stderr, flush=True)
    except Exception as exc:
        update_file_status(conn, file_id, "failed")
        ensure_stored_file(conn, file_id, backup_disk_id, relative_path)
        summary["failed"] += 1
        print(f"Error copiando {file_meta.get('path')}: {exc}", file=sys.stderr, flush=True)


def copy_files(
    conn,
    records,
    backup_disk_id: int,
    destination_root: Path,
    disk_id: str,
    filename_mode: str = "hash",
    total_items: int = 0,
    emit_progress: bool = True,
):
    summary = {
        "scanned": 0,
        "already_registered": 0,
        "reserved": 0,
        "retried": 0,
        "copied_and_verified": 0,
        "renamed": 0,
        "failed": 0,
        "total_items": total_items,
    }
    if emit_progress:
        print_progress(disk_id, 0, total_items)

    progress_step = max(1, total_items // 100) if total_items else 25
    last_progress = 0
    for digest, file_meta in records:
        copy_one_file(conn, digest, file_meta, backup_disk_id, destination_root, summary, filename_mode)
        if emit_progress and summary["scanned"] - last_progress >= progress_step:
            print_progress(disk_id, summary["scanned"], total_items)
            last_progress = summary["scanned"]

    if emit_progress:
        final_total = total_items or summary["scanned"]
        print_progress(disk_id, final_total, final_total)
    return summary


def run_consulter(
    root: str,
    disk_id: str,
    destination_root: Path,
    conn,
    queue_path: str | Path | None = None,
    queue_dir: str | Path | None = None,
    from_queue: bool = False,
    include_system_dirs: bool = False,
    filename_mode: str = "hash",
):
    if filename_mode not in FILENAME_MODES:
        raise ValueError(f"filename_mode invalido: {filename_mode}")
    if not os.path.isdir(root):
        raise FileNotFoundError(f"La ruta de origen no existe o no es directorio: {root}")

    try:
        stats = os.statvfs(root)
        total_bytes = stats.f_blocks * stats.f_frsize
        free_bytes = stats.f_bavail * stats.f_frsize
    except OSError:
        total_bytes = None
        free_bytes = None

    backup_disk_id = get_or_create_backup_disk(
        conn,
        str(root),
        label=disk_id,
        total_bytes=total_bytes,
        free_bytes=free_bytes,
        status="online",
    )

    active_queue_path = Path(queue_path) if queue_path else build_queue_path(disk_id, queue_dir)
    if from_queue:
        if not queue_path:
            raise ValueError("--from-queue requiere --queue-path")
        total_items = count_queue_records(active_queue_path)
        print(f"Leyendo cola de hashes: {active_queue_path}", flush=True)
        records = load_hash_queue(active_queue_path)
        emit_copy_progress = True
    else:
        print("Contando archivos a explorar...", flush=True)
        total_items = count_files(root, include_system_dirs=include_system_dirs)
        print(f"Archivos a explorar: {total_items}", flush=True)
        print(f"Cola de hashes: {active_queue_path}", flush=True)
        progress_step = max(1, total_items // 100) if total_items else 1
        last_progress = {"value": -1}

        def hash_progress(current: int):
            if total_items <= 0:
                return
            if current == total_items or current - last_progress["value"] >= progress_step:
                print_progress(disk_id, current, total_items)
                last_progress["value"] = current

        records = iter_hashed_files(
            root,
            active_queue_path,
            include_system_dirs=include_system_dirs,
            progress_callback=hash_progress,
        )
        emit_copy_progress = False

    summary = copy_files(

class HashQueueWriter:
    def __init__(self, queue_path: str | Path, root: str):
        self.queue_path = Path(queue_path)
        self.status_path = self.queue_path.with_name(self.queue_path.name + ".status.json")
        self.root = root
        self.file = None
        self.count = 0
        self.started_at = datetime.now(timezone.utc).isoformat()

    def __enter__(self):
        self.queue_path.parent.mkdir(parents=True, exist_ok=True)
        self.file = self.queue_path.open("w", encoding="utf-8")
        self.write_status("running")
        return self

    def __exit__(self, exc_type, exc, traceback):
        if self.file:
            self.file.flush()
            self.file.close()
        self.write_status("failed" if exc_type else "done")

    def write_status(self, status: str):
        payload = {
            "status": status,
            "root": self.root,
            "queue_path": str(self.queue_path),
            "count": self.count,
            "hash_threads": HASH_THREADS,
            "chunk_size": CHUNK_SIZE,
            "started_at": self.started_at,
            "updated_at": datetime.now(timezone.utc).isoformat(),
        }
        tmp_path = self.status_path.with_name(self.status_path.name + ".tmp")
        with tmp_path.open("w", encoding="utf-8") as status_file:
            json.dump(payload, status_file, indent=2, ensure_ascii=False)
        tmp_path.replace(self.status_path)

    def write(self, digest: str, file_meta: dict[str, Any]):
        if not self.file:
            return
        record = {"hash": digest, **file_meta}
        self.file.write(json.dumps(record, ensure_ascii=False, sort_keys=True))
        self.file.write("\n")
        self.file.flush()
        self.count += 1
        if self.count % BATCH_SIZE == 0:
            self.write_status("running")


def iter_files(root: str, include_system_dirs: bool | None = None):
    stack = [root]
    while stack:
        current = stack.pop()
        try:
            with os.scandir(current) as entries:
                for entry in entries:
                    try:
                        if entry.is_dir(follow_symlinks=False):
                            if should_skip_dir(entry.name, include_system_dirs):
                                continue
                            stack.append(entry.path)
                            continue
                        if should_skip_file(entry.name):
                            continue
                        _, sep, ext = entry.name.rpartition(".")
                        if sep and ("." + ext.lower()) in EXTS:
                            if entry.is_file(follow_symlinks=False):
                                yield entry.path
                    except (PermissionError, FileNotFoundError, OSError):
                        continue
        except (PermissionError, FileNotFoundError, OSError):
            continue


def count_files(root: str, include_system_dirs: bool | None = None) -> int:
    return sum(1 for _path in iter_files(root, include_system_dirs=include_system_dirs))


def hash_file(path: str) -> str | None:
    try:
        if os.path.getsize(path) == 0:
            return None

        hasher = blake3(max_threads=HASH_THREADS)
        with open(path, "rb") as f:
            while chunk := f.read(CHUNK_SIZE):
                hasher.update(chunk)
        return hasher.hexdigest()

    except (PermissionError, FileNotFoundError, OSError):
        return None


def process_batch(batch: list[str]) -> list[tuple[str, str | None]]:
    results = []
    for path in batch:
        try:
            results.append((path, hash_file(path)))
        except OSError as e:
            print(f"error reading {path}: {e}")
            results.append((path, None))
    return results


def build_file_meta(root: str, path: str, stat_result: os.stat_result) -> dict[str, Any]:
    return {
        "path": path,
        "name": os.path.basename(path),
        "relative_path": os.path.relpath(path, root),
        "size_bytes": stat_result.st_size,
        "modified_at": datetime.fromtimestamp(stat_result.st_mtime, tz=timezone.utc).isoformat(),
        "extension": Path(path).suffix.lower(),
    }


def iter_hashed_files(
    root: str,
    queue_path: str | Path | None = None,
    include_system_dirs: bool | None = None,
    progress_callback=None,
) -> Iterable[tuple[str, dict[str, Any]]]:
    writer_context = HashQueueWriter(queue_path, root) if queue_path else nullcontext(None)
    with writer_context as writer:
        scanned = 0
        for path in iter_files(root, include_system_dirs=include_system_dirs):
            scanned += 1
            digest = hash_file(path)
            if progress_callback:
                progress_callback(scanned)
            if not digest:
                continue

            try:
                stat = os.stat(path)
            except (OSError, PermissionError):
                continue

            file_meta = build_file_meta(root, path, stat)
            if writer:
                writer.write(digest, file_meta)
            yield digest, file_meta


def load_hash_queue(queue_path: str | Path) -> Iterable[tuple[str, dict[str, Any]]]:
    with Path(queue_path).open("r", encoding="utf-8") as queue_file:
        for line_number, line in enumerate(queue_file, start=1):
            line = line.strip()
            if not line:
                continue
            try:
                record = json.loads(line)
            except json.JSONDecodeError as exc:
                print(f"Registro de cola invalido en linea {line_number}: {exc}", file=sys.stderr)
                continue
            digest = record.pop("hash", None)
            if not digest:
                print(f"Registro de cola sin hash en linea {line_number}", file=sys.stderr)
                continue
            yield digest, record


def hash_files(root: str, include_system_dirs: bool | None = None) -> dict[str, dict[str, Any]]:
    hashes: dict[str, dict[str, Any]] = {}
    for digest, file_meta in iter_hashed_files(root, include_system_dirs=include_system_dirs):
        if digest in hashes:
            continue
        hashes[digest] = file_meta
    return dict(sorted(hashes.items(), key=lambda item: item[1]["path"]))

    def consolidar_registro(self, registry):
        consolidated = {}
        identity_index = {}

        for disk_id, info in registry.items():
            identities = self.identidades_info(info)
            target_id = None
            for identity in identities:
                if identity in identity_index:
                    target_id = identity_index[identity]
                    break

            if not target_id:
                target_id = info.get("id") or disk_id
                consolidated[target_id] = info
                consolidated[target_id]["id"] = target_id
            else:
                current = consolidated[target_id]
                current.update({key: value for key, value in info.items() if value})
                current["id"] = target_id
                first_current = current.get("primer_registro")
                first_new = info.get("primer_registro")
                if first_current and first_new:
                    current["primer_registro"] = min(first_current, first_new)
                elif first_new:
                    current["primer_registro"] = first_new

            for identity in identities:
                identity_index[identity] = target_id

        return consolidated

    def guardar_registro(self):
        tmp_path = REGISTRY_PATH.with_suffix(".tmp")
        with tmp_path.open("w", encoding="utf-8") as file:
            json.dump(self.registry, file, indent=2, ensure_ascii=False, sort_keys=True)
        tmp_path.replace(REGISTRY_PATH)

        cleaned = value.replace("\\x20", " ").strip()

        base = MOUNT_BASE / mount_name

        log_method(mensaje)

    def ejecutar(self, comando, timeout=20):
        try:
            return subprocess.run(
                comando,
                capture_output=True,
                check=False,
                text=True,
                timeout=timeout,
            )
        except subprocess.TimeoutExpired:
            self.avisar(f"Timeout ejecutando: {' '.join(comando)}", "warning")
        except FileNotFoundError:
            self.avisar(f"Comando no encontrado: {comando[0]}", "warning")
        except Exception as exc:
            self.avisar(f"Error ejecutando {' '.join(comando)}: {exc}", "error")

        return None

    def obtener_padre_disco(self, device):
        if device.get("DEVTYPE") == "disk":
            return device

        try:
            parent = device.find_parent("block", "disk")
            if parent is not None:
                return parent
        except Exception:
            pass

        current = device
        while current is not None:
            if current.get("DEVTYPE") == "disk":
                return current
            current = current.parent
        return device

    def obtener_propiedad(self, device, keys):
        for key in keys:
            value = device.get(key)
            if value:
                return value
        return None

    def obtener_nombre(self, device, disk_device=None):
        if disk_device is None:
            disk_device = self.obtener_padre_disco(device)
        label = device.get("ID_FS_LABEL") or device.get("ID_FS_LABEL_ENC")
        model = disk_device.get("ID_MODEL") or disk_device.get("ID_MODEL_ENC")
        vendor = disk_device.get("ID_VENDOR") or disk_device.get("ID_VENDOR_ENC")
        serial = disk_device.get("ID_SERIAL_SHORT") or disk_device.get("ID_SERIAL")

        parts = [value for value in (vendor, model) if value]
        if label:
            return label.replace("\\x20", " ")
        if parts:
            return " ".join(parts).replace("_", " ").strip()
        if serial:
            return f"Disco {serial}"
        return device.device_node or device.sys_name

    def particiones_del_disco(self, disk_device):
        partitions = []
        for partition in self.context.list_devices(subsystem="block", DEVTYPE="partition"):
            try:
                parent = partition.find_parent("block", "disk")
            except Exception:
                parent = None
            if parent is not None and parent.sys_name == disk_device.sys_name:
                partitions.append(partition)
        return sorted(partitions, key=lambda item: item.sys_name)

    def esperar_particiones_montables(self, disk_device, segundos=PARTITION_APPEAR_WAIT_SECONDS):
        for elapsed in range(segundos):
            partitions = self.particiones_del_disco(disk_device)
            mountable = [partition for partition in partitions if self.es_particion_montable(partition)]
            if mountable:
                return mountable

            if elapsed in {0, 4, 9}:
                self.avisar(
                    f"Esperando particiones montables de {disk_device.device_node or disk_device.sys_name}... "
                    f"{elapsed + 1}/{segundos}s"
                )
            time.sleep(1)
        return []

    def reintentar_lectura_particiones(self, disk_device):
        disk_node = disk_device.device_node
        if not disk_node:
            return

        self.avisar(f"No aparecieron particiones para {disk_node}; intentando releer tabla...")
        self.ejecutar(["udevadm", "settle"], timeout=8)

        for comando in (["partprobe", disk_node], ["blockdev", "--rereadpt", disk_node]):
            result = self.ejecutar(comando, timeout=8)
            if result and result.returncode == 0:
                self.avisar(f"Comando exitoso: {' '.join(comando)}")
                self.ejecutar(["udevadm", "settle"], timeout=8)
                return
            if result and result.stderr.strip():
                self.avisar(
                    f"No se pudo ejecutar {' '.join(comando)}: {result.stderr.strip()}",
                    "warning",
                )

    def uuid_tabla_particiones(self, disk_device, partitions):
        table_uuid = disk_device.get("ID_PART_TABLE_UUID")
        if table_uuid:
            return table_uuid

        for partition in partitions:
            table_uuid = partition.get("ID_PART_TABLE_UUID")
            if table_uuid:
                return table_uuid
        return None

    def uuids_particiones(self, partitions):
        values = []
        for partition in partitions:
            part_uuid = partition.get("ID_PART_ENTRY_UUID")
            fs_uuid = partition.get("ID_FS_UUID")
            if part_uuid:
                values.append(f"partuuid:{part_uuid}")
            if fs_uuid:
                values.append(f"fsuuid:{fs_uuid}")
        return sorted(set(values))

    def obtener_huella_disco(self, device):
        disk_device = self.obtener_padre_disco(device)
        partitions = self.particiones_del_disco(disk_device)
        serial = self.obtener_propiedad(disk_device, ["ID_SERIAL", "ID_SERIAL_SHORT"])
        wwn = disk_device.get("ID_WWN")
        table_uuid = self.uuid_tabla_particiones(disk_device, partitions)
        partition_uuids = self.uuids_particiones(partitions)

        if wwn:
            return "wwn", wwn
        if table_uuid:
            return "partition_table_uuid", table_uuid
        if partition_uuids:
            return "partition_uuids", "|".join(partition_uuids)
        if serial:
            return "serial", serial

        fallback_values = [
            disk_device.get("ID_BUS"),
            disk_device.get("ID_VENDOR"),
            disk_device.get("ID_MODEL"),
            disk_device.get("ID_REVISION"),
            disk_device.get("size"),
        ]
        raw = "|".join(value for value in fallback_values if value)
        if raw:
            return "weak_hardware_fallback", raw

        return "temporary_kernel_path", disk_device.device_path or disk_device.sys_name

    def crear_id_disco(self, device):
        source, raw = self.obtener_huella_disco(device)
        digest = hashlib.sha256(f"{source}:{raw}".encode("utf-8")).hexdigest()[:16]
        return f"disk-{digest}"

    def huella_es_fuerte(self, source):
        return source in {"wwn", "partition_table_uuid", "partition_uuids", "serial"}

    def obtener_info_disco(self, device):
        disk_device = self.obtener_padre_disco(device)
        partitions = self.particiones_del_disco(disk_device)
        id_fuente, id_raw = self.obtener_huella_disco(device)
        disk_id = self.crear_id_disco(device)
        return {
            "id": disk_id,
            "nombre": self.obtener_nombre(device, disk_device),
            "serial": disk_device.get("ID_SERIAL") or disk_device.get("ID_SERIAL_SHORT"),
            "wwn": disk_device.get("ID_WWN"),
            "tabla_particiones_uuid": self.uuid_tabla_particiones(disk_device, partitions),
            "particiones_uuid": self.uuids_particiones(partitions),
            "id_fuente": id_fuente,
            "id_valor": id_raw,
            "modelo": disk_device.get("ID_MODEL"),
            "vendor": disk_device.get("ID_VENDOR"),
            "bus": disk_device.get("ID_BUS"),
            "device_node": disk_device.device_node,
            "sys_name": disk_device.sys_name,
        }

    def identidades_info(self, info):
        identities = []
        for key in ("wwn", "tabla_particiones_uuid"):
            value = info.get(key)
            if value:
                identities.append(f"{key}:{value}")

        for value in info.get("particiones_uuid") or []:
            identities.append(f"particion_uuid:{value}")

        if info.get("serial"):
            identities.append(f"serial:{info['serial']}")

        id_source = info.get("id_fuente")
        id_value = info.get("id_valor")
        if id_source in {"wwn", "partition_table_uuid", "partition_uuids", "serial"} and id_value:
            identities.append(f"{id_source}:{id_value}")

        return identities

    def buscar_id_existente(self, info):
        identities = set(self.identidades_info(info))
        if not identities:
            return None

        for disk_id, saved_info in self.registry.items():
            if identities.intersection(self.identidades_info(saved_info)):
                return disk_id
        return None

    def registrar_disco(self, info, action):
        with self.registry_lock:
            now = datetime.now(timezone.utc).isoformat()
            canonical_id = info["id"]
            existing_id = self.buscar_id_existente(info)
            target_id = canonical_id

            if existing_id and existing_id != canonical_id:
                existing_info = self.registry.get(existing_id, {})
                old_source = existing_info.get("id_fuente")
                new_source = info.get("id_fuente")
                if not self.huella_es_fuerte(new_source) or self.huella_es_fuerte(old_source):
                    target_id = existing_id
                else:
                    logger.info(
                        f"Migrando registro {existing_id} a {canonical_id} "
                        f"porque ahora hay huella fuerte ({new_source})."
                    )
            elif existing_id:
                target_id = existing_id

            current = {}
            if existing_id and existing_id in self.registry:
                current.update(self.registry[existing_id])
            current.update(self.registry.get(target_id, {}))
            current.update({key: value for key, value in info.items() if value})
            current["id"] = target_id
            current["ultimo_evento"] = action
            current["ultima_vez_visto"] = now
            current.setdefault("primer_registro", now)

            if existing_id and existing_id != target_id:
                self.registry.pop(existing_id, None)
            self.registry[target_id] = current
            self.guardar_registro()
            info["id"] = target_id

    def punto_montaje_actual(self, device_node):
        result = self.ejecutar(["findmnt", "-rn", "-S", device_node, "-o", "TARGET"], timeout=5)
        if result and result.returncode == 0 and result.stdout.strip():
            return self.decodificar_findmnt(result.stdout.strip().splitlines()[0])

        for part in psutil.disk_partitions(all=True):
            if part.device == device_node:
                return part.mountpoint
        return None

    def esperar_montaje(self, device_node, segundos=AUTO_MOUNT_WAIT_SECONDS):
        for elapsed in range(segundos):
            mountpoint = self.punto_montaje_actual(device_node)
            if mountpoint:
                return mountpoint
            if elapsed in {0, 4}:
                self.avisar(
                    f"Esperando montaje automático de {device_node}... "
                    f"{elapsed + 1}/{segundos}s"
                )
            time.sleep(1)
        return None

    def montar_con_udisksctl(self, device_node):
        self.avisar(f"Intentando montar {device_node} con udisksctl...")
        result = self.ejecutar(
            ["udisksctl", "mount", "-b", device_node],
            timeout=UDISKSCTL_TIMEOUT_SECONDS,
        )
        if not result or result.returncode != 0:
            mountpoint = self.punto_montaje_actual(device_node)
            if mountpoint:
                self.avisar(f"{device_node} ya estaba montado en: {mountpoint}", "success")
                return mountpoint

            if result and result.stderr.strip():
                self.avisar(
                    f"udisksctl no pudo montar {device_node}: {result.stderr.strip()}",
                    "warning",
                )
            return None

        mountpoint = self.esperar_montaje(device_node, segundos=3)
        if mountpoint:
            return mountpoint

        match = re.search(r" at (.+?)\.?$", result.stdout.strip())
        if match:
            return match.group(1)
        return None

    def montar_con_mount_auto(self, device, disk_id):
        device_node = device.device_node
        label = device.get("ID_FS_LABEL") or device.get("ID_FS_LABEL_ENC")
        mount_name = self.limpiar_nombre_montaje(label or f"disk_listener_{disk_id}_{Path(device_node).name}")
        mountpoint = self.crear_punto_montaje_unico(mount_name)
        try:
            mountpoint.mkdir(parents=True, exist_ok=True)
        except PermissionError:
            logger.error(f"Sin permisos para crear {mountpoint}")
            return None

        mount_command = ["mount", "-t", "auto"]
        fs_type = (device.get("ID_FS_TYPE") or "").lower()
        if fs_type in {"vfat", "exfat", "ntfs", "ntfs3"}:
            mount_command.extend(["-o", f"uid={os.getuid()},gid={os.getgid()},umask=022"])
        mount_command.extend([device_node, str(mountpoint)])

        self.avisar(f"Intentando montaje manual de {device_node} en {mountpoint}...")
        result = self.ejecutar(mount_command, timeout=MANUAL_MOUNT_TIMEOUT_SECONDS)
        if result and result.returncode == 0:
            return str(mountpoint)

        if result and result.stderr.strip():
            self.avisar(
                f"mount -t auto falló para {device_node}: {result.stderr.strip()}",
                "warning",
            )
        return None

    def montar_particion(self, device, disk_id):
        device_node = device.device_node
        if not device_node:
            return None

        if not self.es_particion_montable(device):
            self.avisar(
                f"{device_node} detectado, pero no tiene filesystem montable.",
                "warning",
            )
            return None

        fs_type = device.get("ID_FS_TYPE") or "desconocido"
        label = device.get("ID_FS_LABEL") or device.get("ID_FS_LABEL_ENC") or "sin etiqueta"
        self.avisar(f"Partición montable detectada: {device_node} | FS: {fs_type} | Nombre: {label}")

        mountpoint = self.esperar_montaje(device_node)
        if mountpoint:
            self.avisar(f"{device_node} ya está montado en: {mountpoint}", "success")
            return mountpoint

        mountpoint = self.montar_con_udisksctl(device_node)
        if mountpoint:
            self.avisar(f"{device_node} montado con udisksctl en: {mountpoint}", "success")
            return mountpoint

        mountpoint = self.montar_con_mount_auto(device, disk_id)
        if mountpoint:
            self.avisar(f"{device_node} montado manualmente en: {mountpoint}", "success")
            return mountpoint

        self.avisar(
            f"No se pudo montar {device_node} después de "
            f"{AUTO_MOUNT_WAIT_SECONDS + UDISKSCTL_TIMEOUT_SECONDS + MANUAL_MOUNT_TIMEOUT_SECONDS}s. "
            "Revisa disk_listener.log para el error de udisksctl/mount.",
            "error",
        )
        return None

    def iniciar_proceso_individual(self, info, mountpoint):
        if not self.consulter_script.exists():
            self.avisar(
                f"No se encontró {self.consulter_script}; no se iniciará el proceso de copia.",
                "error",
            )
            return

        if not self.consulter_db_dsn:
            self.avisar(
                "CONSULTER_DB_DSN no está definido; no se iniciará el proceso de copia.",
                "warning",
            )
            return

        disk_id = info.get("id") or info.get("nombre") or "unknown_disk"
        with self.process_lock:
            proc = self.disk_processes.get(disk_id)
            if proc is not None and proc.poll() is None:
                self.avisar(
                    f"Ya existe un proceso activo para {disk_id}; no se iniciará otro.",
                    "info",
                )
                return
            self.disk_processes.pop(disk_id, None)

        command = [
            str(self.python_path),
            str(self.consulter_script),
            mountpoint,
            "--disk-id",
            disk_id,
            "--output-path",
            str(self.output_root),
            "--db-dsn",
            self.consulter_db_dsn,
            "--skip-schema-init",
        ]

        log_path = self.process_log_dir / f"{disk_id}.log"
        self.avisar(
            f"Iniciando proceso individual para {disk_id} en {mountpoint}. Log: {log_path}",
            "info",
        )

        try:
            log_file = open(log_path, "a", encoding="utf-8")
        except Exception as exc:
            self.avisar(
                f"No se pudo abrir el log de proceso para {disk_id}: {exc}",
                "error",
            )
            return

        env = os.environ.copy()
        env["PYTHONUNBUFFERED"] = "1"
        stdout_pipe = subprocess.PIPE

        try:
            proc = subprocess.Popen(
                command,
                stdout=stdout_pipe,
                stderr=log_file,
                env=env,
                start_new_session=True,
                text=True,
                bufsize=1,
            )
        except Exception as exc:
            self.avisar(
                f"No se pudo iniciar el proceso de copia para {disk_id}: {exc}",
                "error",
            )
            log_file.close()
            return

        log_lock = threading.Lock()
        with self.process_lock:
            self.disk_processes[disk_id] = proc

        threading.Thread(
            target=self.read_process_stdout,
            args=(disk_id, log_file, proc.stdout, log_lock),
            daemon=True,
        ).start()

        def monitor_process():
            exit_code = proc.wait()
            with log_lock:
                log_file.write(f"\n=== Proceso {disk_id} finalizó con código {exit_code} ===\n")
                log_file.flush()
                log_file.close()
            with self.process_lock:
                self.disk_processes.pop(disk_id, None)
                remaining = len(self.disk_processes)
            if exit_code == 0:
                self.avisar(
                    f"Proceso individual completado: {disk_id} -> {mountpoint}",
                    "success",
                )
            else:
                self.avisar(
                    f"Proceso individual falló ({disk_id}) con código {exit_code}",
                    "error",
                )
            if remaining == 0:
                self.avisar(
                    "Todos los discos conectados han terminado. Puedes desconectar uno y conectar otro.",
                    "success",
                )

        threading.Thread(target=monitor_process, daemon=True).start()

    def manejar_add(self, device):
        devtype = device.get("DEVTYPE")
        if devtype not in {"disk", "partition"}:
            return

        device = self.refrescar_device(device)
        devtype = device.get("DEVTYPE")

        if not self.es_particion_montable(device):
            if devtype == "disk":
                disk_node = device.device_node or device.sys_name
                self.avisar(f"Disco físico detectado: {disk_node}. Buscando particiones montables...")
                mountable_partitions = self.esperar_particiones_montables(device)
                if not mountable_partitions:
                    self.reintentar_lectura_particiones(device)
                    mountable_partitions = self.esperar_particiones_montables(device, segundos=5)

                if not mountable_partitions:
                    info = self.obtener_info_disco(device)
                    self.registrar_disco(info, "connect_failed")
                    with self.active_lock:
                        self.active_devices[device.sys_name] = info
                        if device.device_node:
                            self.active_devices[device.device_node] = info
                    table_type = device.get("ID_PART_TABLE_TYPE") or "sin tabla"
                    table_uuid = device.get("ID_PART_TABLE_UUID") or "sin uuid"
                    self.avisar(
                        f"Conectado: {info['nombre']} | ID: {info['id']} | "
                        f"Dispositivo: {disk_node} | No se pudo montar: "
                        "el disco fue detectado, pero no existe ninguna partición montable "
                        f"({table_type}, {table_uuid}).",
                        "error",
                    )
                    return

                for partition in mountable_partitions:
                    self.procesar_evento("add", partition)
                return

            self.avisar(
                f"Conectado: {device.device_node or device.sys_name} | "
                "No se pudo montar: sin filesystem detectado",
                "warning",
            )
            return

        id_fuente, _ = self.obtener_huella_disco(device)
        if devtype == "disk" and not self.huella_es_fuerte(id_fuente):
            self.avisar(
                f"Detectado {device.device_node or device.sys_name}, "
                f"pero la huella aun es debil ({id_fuente}); intentando montar de todos modos."
            )

        info = self.obtener_info_disco(device)
        mountpoint = None
        if self.es_particion_montable(device):
            mountpoint = self.montar_particion(device, info["id"])
            info["particion"] = device.device_node
            info["filesystem"] = device.get("ID_FS_TYPE")
            info["filesystem_uuid"] = device.get("ID_FS_UUID")
            info["particion_uuid"] = device.get("ID_PART_ENTRY_UUID")
            info["label"] = device.get("ID_FS_LABEL") or device.get("ID_FS_LABEL_ENC")
            if mountpoint:
                info["mountpoint"] = mountpoint

        self.registrar_disco(info, "connect")
        with self.active_lock:
            self.active_devices[device.sys_name] = info
            if device.device_node:
                self.active_devices[device.device_node] = info

        mensaje = f"Conectado: {info['nombre']} | ID: {info['id']}"
        if device.device_node:
            mensaje += f" | Dispositivo: {device.device_node}"
        if mountpoint:
            mensaje += f" | Montado en: {mountpoint}"
            self.avisar(mensaje, "success")
            self.iniciar_proceso_individual(info, mountpoint)
        else:
            mensaje += " | No se pudo montar"
            self.avisar(mensaje, "warning")

    def obtener_id_seguro(self, raw_value):
        safe = re.sub(r"[^A-Za-z0-9]+", "_", str(raw_value).strip())
        safe = re.sub(r"_+", "_", safe).strip("_")
        return safe.upper() if safe else "DISK"

    def scan_existing_mounts(self):
        if not MOUNT_BASE.exists():
            return

        partitions = psutil.disk_partitions(all=False)
        for part in partitions:
            mountpoint = part.mountpoint
            if not mountpoint.startswith(str(MOUNT_BASE)):
                continue
            if mountpoint == str(MOUNT_BASE):
                continue

            device_node = part.device
            self.avisar(f"Montaje existente detectado: {mountpoint} ({device_node})", "info")
            try:
                device = pyudev.Devices.from_device_file(self.context, device_node)
            except Exception:
                device = None

            if device is not None:
                self.procesar_evento("add", device)
            else:
                disk_id = self.obtener_id_seguro(Path(mountpoint).name)
                info = {"id": disk_id, "nombre": Path(mountpoint).name}
                self.iniciar_proceso_individual(info, mountpoint)

    def test_db_connection(self):
        if not self.consulter_db_dsn:
            self.avisar(
                "CONSULTER_DB_DSN no está definido; no se puede iniciar el listener.",
                "error",
            )
            return False
        try:
            conn = psycopg2.connect(self.consulter_db_dsn)
            conn.close()
            return True
        except Exception as exc:
            self.avisar(
                f"Error de conexión a la base de datos: {exc}",
                "error",
            )
            return False

    def format_progress_bar(self, current: int, total: int, width: int = 30) -> str:
        if total <= 0:
            return f"procesados {current} archivos..."
        ratio = min(max(current / total, 0.0), 1.0)
        filled = int(ratio * width)
        bar = "█" * filled + "-" * (width - filled)
        return f"[{bar}] {int(ratio * 100):3d}% ({current}/{total})"

    def update_progress(self, disk_id: str, current: int, total: int):
        with self.progress_lock:
            self.progress_status[disk_id] = (current, total)
            bar = self.format_progress_bar(current, total)
            print(f"[{disk_id}] {bar}", flush=True)

    def read_process_stdout(self, disk_id: str, log_file, stdout_pipe, log_lock):
        try:
            assert stdout_pipe is not None
            for raw_line in iter(stdout_pipe.readline, ""):
                if not raw_line:
                    break
                stripped = raw_line.rstrip("\n")
                if stripped.startswith("PROGRESS:"):
                    parts = stripped.split(":")
                    if len(parts) == 4:
                        _, parsed_id, current, total = parts
                        if parsed_id == disk_id:
                            try:
                                self.update_progress(parsed_id, int(current), int(total))
                            except ValueError:
                                pass
                    continue
                with log_lock:
                    log_file.write(raw_line)
                    log_file.flush()
        finally:
            if stdout_pipe is not None:
                stdout_pipe.close()

    def manejar_remove(self, device):
        with self.active_lock:
            info = self.active_devices.get(device.sys_name)
            if not info and device.device_node:
                info = self.active_devices.get(device.device_node)
        if not info:
            info = self.obtener_info_disco(device)

        self.registrar_disco(info, "disconnect")
        mensaje = f"Desconectado: {info['nombre']} | ID: {info['id']}"
        if device.device_node:
            mensaje += f" | Dispositivo: {device.device_node}"

        self.avisar(mensaje, "warning")

    def clave_evento(self, action, device):
        return action, device.device_node or device.sys_name or device.device_path

    def procesar_evento(self, action, device):
        key = self.clave_evento(action, device)
        with self.processing_lock:
            if key in self.processing_devices:
                return
            self.processing_devices.add(key)

        try:
            if action == "add":
                self.manejar_add(device)
            elif action == "remove":
                self.manejar_remove(device)
        except Exception as exc:
            logger.exception(f"Error procesando evento {action}: {exc}")
        finally:
            with self.processing_lock:
                self.processing_devices.discard(key)

    def iniciar(self):
        self.avisar("Listener de discos activo. Conecta o desconecta un disco.")
        if not self.test_db_connection():
            self.avisar("El listener no puede iniciarse sin conexión válida a la base de datos.", "error")
            return

        if not self.initialize_db_schema():
            self.avisar("No se pudo inicializar el esquema de la base de datos. El listener no continuará.", "error")
            return

        self.scan_existing_mounts()

        for action, device in self.monitor:
            thread = threading.Thread(
                target=self.procesar_evento,
                args=(action, device),
                daemon=True,
            )
            thread.start()

def read_env_file(path: Path) -> dict[str, str]:
    values: dict[str, str] = {}
    if not path.exists():
        return values
    for raw_line in path.read_text(encoding="utf-8").splitlines():
        line = raw_line.strip()
        if not line or line.startswith("#") or "=" not in line:
            continue
        key, value = line.split("=", 1)
        values[key.strip()] = value.strip().strip('"').strip("'")
    return values


def dsn_from_env(db_name: str | None = None) -> str:
    env_file = read_env_file(BASE_DIR / ".env")
    existing = os.environ.get("CONSULTER_DB_DSN")
    if existing:
        return replace_db_name(existing, db_name) if db_name else existing

    name = db_name or env_file.get("DB_NAME") or "scrapper"
    parts = [f"dbname={name}"]
    if env_file.get("DB_USER"):
        parts.append(f"user={env_file['DB_USER']}")
    if env_file.get("DB_PASS"):
        parts.append(f"password={env_file['DB_PASS']}")
    if env_file.get("DB_HOST"):
        parts.append(f"host={env_file['DB_HOST']}")
    if env_file.get("DB_PORT"):
        parts.append(f"port={env_file['DB_PORT']}")
    return " ".join(parts)


def replace_db_name(dsn: str, db_name: str | None) -> str:
    if not db_name:
        return dsn
    parts = shlex.split(dsn)
    replaced = False
    for index, part in enumerate(parts):
        if part.startswith("dbname="):
            parts[index] = f"dbname={db_name}"
            replaced = True
            break
    if not replaced:
        parts.insert(0, f"dbname={db_name}")
    return " ".join(parts)

def run_lsblk() -> list[dict]:
    command = [
        "lsblk",
        "-J",
        "-o",
        "PATH,NAME,TYPE,SIZE,LABEL,FSTYPE,MOUNTPOINT,TRAN,MODEL",
    ]
    result = subprocess.run(command, check=False, capture_output=True, text=True)
    if result.returncode != 0:
        print(result.stderr.strip() or "No se pudo ejecutar lsblk.")
        return []
    try:
        payload = json.loads(result.stdout)
    except json.JSONDecodeError:
        return []

    disks: list[dict] = []

    def walk(node: dict, parent: dict | None = None):
        inherited = parent or {}
        merged = {
            "path": node.get("path"),
            "name": node.get("name"),
            "type": node.get("type"),
            "size": node.get("size"),
            "label": node.get("label"),
            "fstype": node.get("fstype"),
            "mountpoint": node.get("mountpoint"),
            "tran": node.get("tran") or inherited.get("tran"),
            "model": node.get("model") or inherited.get("model"),
        }
        if merged["type"] == "part" and merged["fstype"]:
            disks.append(merged)
        for child in node.get("children") or []:
            walk(child, merged)

    for block in payload.get("blockdevices") or []:
        walk(block)
    return disks


def disk_label(entry: dict) -> str:
    label = entry.get("label") or entry.get("model") or entry.get("name") or entry.get("path")
    bits = [label]
    if entry.get("size"):
        bits.append(entry["size"])
    if entry.get("fstype"):
        bits.append(entry["fstype"])
    if entry.get("mountpoint"):
        bits.append(f"montado: {entry['mountpoint']}")
    else:
        bits.append("sin montar")
    return " | ".join(bits)


def mount_entry(entry: dict) -> str | None:
    if entry.get("mountpoint"):
        return entry["mountpoint"]
    device_path = entry.get("path")
    if not device_path:
        return None
    result = subprocess.run(["udisksctl", "mount", "-b", device_path], capture_output=True, text=True)
    output = (result.stdout or "") + (result.stderr or "")
    if result.returncode != 0:
        print(output.strip() or f"No se pudo montar {device_path}.")
        return None
    match = re.search(r" at (.+?)\.?$", output.strip())
    if match:
        return match.group(1)
    for refreshed in run_lsblk():
        if refreshed.get("path") == device_path and refreshed.get("mountpoint"):
            return refreshed["mountpoint"]
    return None


def find_mountpoint(path: Path) -> Path:
    current = path.resolve()
    while current != current.parent:
        if os.path.ismount(current):
            return current
        current = current.parent
    return current


def validate_manual_path(raw_path: str) -> tuple[bool, Path | None, str]:
    if not raw_path.strip():
        return False, None, "No se ingreso ruta."
    path = Path(raw_path).expanduser()
    if not path.exists():
        return False, path, "La carpeta no existe o no esta montada."
    if not path.is_dir():
        return False, path, "La ruta existe, pero no es una carpeta."
    try:
        mountpoint = find_mountpoint(path)
    except OSError:
        return False, path, "La carpeta no es accesible o no esta montada."
    if str(path).startswith(str(MOUNT_BASE)) and mountpoint == Path("/"):
        return False, path, "La carpeta parece estar bajo /media, pero no esta montada."
    return True, path, ""


def validate_manual_file(raw_path: str) -> tuple[bool, Path | None, str]:
    if not raw_path.strip():
        return False, None, "No se ingreso ruta."
    path = Path(raw_path).expanduser()
    if not path.exists():
        return False, path, "El archivo no existe o no esta accesible."
    if not path.is_file():
        return False, path, "La ruta existe, pero no es un archivo."
    try:
        with open(path, "rb") as f:
            f.read(1)
    except OSError as e:
        return False, path, f"El archivo no es legible: {e}"
    return True, path, ""


def render_progress(current: int, total: int, width: int = 34):
    if total <= 0:
        sys.stdout.write(f"\rProcesados {current} archivos...")
        sys.stdout.flush()
        return
    ratio = min(max(current / total, 0.0), 1.0)
    filled = int(ratio * width)
    bar = "#" * filled + "-" * (width - filled)
    percent = int(ratio * 100)
    sys.stdout.write(f"\r[{bar}] {percent:3d}% ({current}/{total})")
    sys.stdout.flush()


def run_copier_for_path(config: dict, source_path: Path, disk_id: str):
    profile_name, profile = active_profile(config)
    workers = prompt_int("Workers para blake3", DEFAULT_WORKERS)
    copy_root = Path(profile["copy_root"]).expanduser()
    copy_root.mkdir(parents=True, exist_ok=True)

    command = [
        str(PYTHON_BIN),
        str(COPIER_SCRIPT),
        str(source_path),
        "--disk-id",
        disk_id,
        "--output-path",
        str(copy_root),
        "--db-dsn",
        profile["db_dsn"],
        "--filename-mode",
        config.get("filename_mode", "hash"),
    ]
    env = os.environ.copy()
    env["CONSULTER_HASH_THREADS"] = str(workers)
    env["PYTHONUNBUFFERED"] = "1"

    print(f"\nPerfil: {profile_name}")
    print(f"Origen: {source_path}")
    print(f"Destino: {copy_root}")
    print(f"Modo nombre: {config.get('filename_mode', 'hash')}")
    print(f"Workers blake3: {workers}\n")

    process = subprocess.Popen(
        command,
        stdout=subprocess.PIPE,
        stderr=subprocess.STDOUT,
        text=True,
        env=env,
        bufsize=1,
    )
    progress_active = False
    assert process.stdout is not None
    for raw_line in process.stdout:
        line = raw_line.rstrip("\n")
        if line.startswith("PROGRESS:"):
            parts = line.split(":")
            if len(parts) == 4:
                try:
                    render_progress(int(parts[2]), int(parts[3]))
                    progress_active = True
                except ValueError:
                    pass
            continue
        if progress_active:
            print()
            progress_active = False
        print(line)
    if progress_active:
        print()
    exit_code = process.wait()
    print(f"Proceso terminado con codigo {exit_code}\n")

    # Crear directorio temporal para el archivo

                    item.unlink()
            temp_dir.rmdir()

set -euo pipefail

# Wrapper for code/consulter_copier.py to process USB disks and write a per-disk log.
# Usage:
#   CONSULTER_DB_DSN="dbname=scrapper" ./run_usb_copy.sh
# or export CONSULTER_DB_DSN first.

DB_DSN=${CONSULTER_DB_DSN:-}
if [[ -z "$DB_DSN" ]]; then
  echo "Error: CONSULTER_DB_DSN is not set. Export it before running the script."
  echo "Example: export CONSULTER_DB_DSN='dbname=scrapper'"
  exit 1
fi

PYTHON="/home/uzr/v_envs/Scrapper/bin/python"
CONSULTER="/home/uzr/code/consulter_copier.py"
OUTPUT_ROOT="/home/uzr/data_full"
LOG_FILE="/home/uzr/code/usb_copy_run.log"
MOUNT_ROOT="/media/$(whoami)"

mkdir -p "$(dirname "$LOG_FILE")"
mkdir -p "$OUTPUT_ROOT"

exec >>"$LOG_FILE" 2>&1

echo "========================================"
echo "USB copy run started: $(date +'%F %T')"
echo "DB DSN: ${DB_DSN}"
echo "Output root: ${OUTPUT_ROOT}"
echo "Log file: ${LOG_FILE}"
echo "Mount root: ${MOUNT_ROOT}"
echo ""

if [[ ! -d "$MOUNT_ROOT" ]]; then
  echo "ERROR: mount root does not exist: ${MOUNT_ROOT}"
  exit 1
fi

mapfile -t MOUNT_PATHS < <(find "$MOUNT_ROOT" -maxdepth 1 -mindepth 1 -type d | sort)
if [[ ${#MOUNT_PATHS[@]} -eq 0 ]]; then
  echo "No mounted disks found under ${MOUNT_ROOT}."
  exit 1
fi

sanitize_disk_id() {
  local label="$1"
  local sanitized
  sanitized=$(basename "$label" | tr '[:lower:]' '[:upper:]' | sed 's/[^A-Z0-9]/_/g' | sed 's/^_*//; s/_*$//; s/_\+/_/g')
  if [[ -z "$sanitized" ]]; then
    sanitized="DISK_$2"
  fi
  echo "$sanitized"
}

for i in "${!MOUNT_PATHS[@]}"; do
  mount_path="${MOUNT_PATHS[$i]}"
  disk_id=$(sanitize_disk_id "$mount_path" "$((i + 1))")

  echo "---"
  echo "Processing disk: ${disk_id}"
  echo "Mount path: ${mount_path}"
  echo "Start: $(date +'%F %T')"

  if [[ ! -d "$mount_path" ]]; then
    echo "ERROR: mount path does not exist: ${mount_path}"
    continue
  fi

  set +e
  PYTHONUNBUFFERED=1 "$PYTHON" "$CONSULTER" "$mount_path" \
    --disk-id "$disk_id" \
    --output-path "$OUTPUT_ROOT" \
    --db-dsn "$DB_DSN"
  rc=$?
  set -e

  echo "Exit code: $rc"
  echo "End: $(date +'%F %T')"
  echo ""
done

echo "USB copy run finished: $(date +'%F %T')"
echo "========================================"
